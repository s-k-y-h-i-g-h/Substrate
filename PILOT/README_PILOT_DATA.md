# PILOT/pilot_results/ — Directory for Pilot Outputs

**This directory is gitignored.** Pilot data is not committed to the public repository.

At pilot close, store here:

- `pilot_log_XXXX-MM-DD.md` — anonymised daily uptake summary
- `partner_debrief_XXXX-MM-DD.md` — debrief notes (consented)
- `pilots_results.md` — public-facing pilot summary (no individual data)
- `lessons_learned.md` — internal iteration notes (board-only review)
