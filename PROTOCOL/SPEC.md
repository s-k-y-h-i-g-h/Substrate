## Methodology

### Evidence Grading

| Tier | Definition | Examples |
|------|-------------|---------|
| **T1** | Published RCT in target population (homeless, low-income, addiction recovery) | [none identified yet] |
| **T2** | RCT in general population; consistent observational data | Vitamin D + K2 (RCT for bone health), Omega-3 (cardiovascular RCTs) |
| **T3** | Strong mechanistic rationale + observational in related populations | Creatine (neurological), NAC (addiction recovery studies) |
| **T4** | Mechanistic in vitro / animal data only; traditional use | Lion's Mane (animal models, traditional medicine) |
| **T5** | Anecdotal / theoretical only | — |

**Target bar for inclusion in Core 5: T2 or better.** Lower-tier ingredients may be included in Longevity/Cognitive tiers with explicit downgrade citation and monitoring commitment.

## Core 5 — nutritional adequacy baseline

Designed to address the most common nutritional deficiencies observed in homeless and low-income populations: Vitamin D, Magnesium, Omega-3, B-vitamins, creatine.

### 1. Vitamin D3 + K2 (MK-7)

| Field | Value |
|-------|-------|
| Dose per unit | 2000 IU D3 (50 mcg) + 100 mcg K2 MK-7 |
| Rationale | UK winter deficiency >40% in general population; homelessness correlates with 70-90% deficiency rates |
| Timing | Morning with food (fat-soluble) |
| Evidence tier | T2 |
| Contraindications | Hypercalcaemia, granulomatous disease, warfarin (K2 interaction) |
| Supplier spec | <60 days shelf life remaining on receipt; third-party HPLC CoA |
| Unit cost target | <£0.12/unit at 10,000-unit bulk |

### 2. Magnesium glycinate

| Field | Value |
|-------|-------|
| Dose per unit | 200mg elemental Mg (as magnesium glycinate) |
| Rationale | Mg deficiency linked to sympathetic tone, sleep disruption, muscle cramping — all elevated in homeless populations |
| Timing | Evening, split (AM/PM) if tolerated |
| Evidence tier | T2 |
| Contraindications | Renal impairment (eGFR <30), complete heart block |
| Supplier spec | Chelated magnesium only (no oxide); CoA required |
| Unit cost target | <£0.10/unit at 10,000-unit bulk |

### 3. Omega-3 (EPA/DHA)

| Field | Value |
|-------|-------|
| Dose per unit | 1000mg total EPA+DHA (minimum 500mg EPA, 300mg DHA) |
| Rationale | Neuroinflammation, mood regulation; omega-3 deficiency correlates with substance use severity |
| Timing | With meal (fat-soluble) |
| Evidence tier | T2 |
| Contraindications | Anticoagulant use; shellfish allergy (check source — use algal oil for vegan variant) |
| Supplier spec | IFOS 5-star or equivalent third-party oxidation test; mercury <5ppb |
| Unit cost target | <£0.25/unit at 5,000-unit bulk |

### 4. Methylated B-Complex

| Field | Value |
|-------|-------|
| Dose per unit | Folate (5-MTHF 400mcg) + B6 (P5P 25mg) + B12 (methylcobalamin 500mcg) + B2 (R5P 25mg) |
| Rationale | MTHFR polymorphism common (~40% C677T heterozygosity); unmetabolised folic acid useless in significant portion of population |
| Timing | Morning |
| Evidence tier | T2 (folate/B12); T3 (methylated vs unmethylated differential) |
| Contraindications | High-dose B6 (>100mg/day long-term) — monitor for sensory neuropathy; this formulation stays well below that |
| Supplier spec | Methylated forms only; no synthetic folic acid; CoA required |
| Unit cost target | <£0.15/unit at 10,000-unit bulk |

### 5. Creatine monohydrate

| Field | Value |
|-------|-------|
| Dose per unit | 3000mg creatine monohydrate (micronised) |
| Rationale | Cognitive support, sarcopenia prevention, mood. One of the most studied supplements. Particularly relevant for populations with low dietary protein. |
| Timing | Any time; consistent timing preferred |
| Evidence tier | T2+ (neuro applications T3) |
| Contraindications | Renal impairment — monitor if applicable; otherwise very safe |
| Supplier spec | Creapure or verified equivalent; dissolution test acceptable alternative to HPLC |
| Unit cost target | <£0.08/unit at 20,000-unit bulk |

## Longevity Tier

### NAC (N-Acetylcysteine)

| Field | Value |
|-------|-------|
| Dose per unit | 600mg |
| Evidence tier | T3 |
| Rationale | Glutathione precursor; attenuates craving and relapse in substance use research |
| Contraindications | Activated charcoal interaction; asthma (rare exacerbation) |

### Glycine

| Field | Value |
|-------|-------|
| Dose per unit | 3000mg |
| Evidence tier | T3 |
| Rationale | Collagen synthesis, sleep quality, NMDA glycine site modulation |
| Contraindications | None at this dose |

### Taurine

| Field | Value |
|-------|-------|
| Dose per unit | 1000mg |
| Evidence tier | T3 |
| Rationale | Osmoregulation, cardiac rhythm support, GABA modulation |
| Contraindications | None at this dose; bile acid conjugation consideration |

### Spermidine (wheat germ extract)

| Field | Value |
|-------|-------|
| Dose per unit | 1mg |
| Evidence tier | T3 |
| Rationale | Autophagy induction; emerging animal/fly data; human data limited |
| Contraindications | Wheat allergy (choose rice-derived if sourcing allows) |

## Cognitive Tier

### CDP-Choline (Citicoline)

| Field | Value |
|-------|-------|
| Dose per unit | 250mg |
| Evidence tier | T3 |
| Rationale | Phosphatidylcholine precursor; neuroplasticity; modest memory/brain blood flow data |
| Contraindications | Trimethylaminuria (fish odour syndrome — choline breakdown product) |

### ALCAR (Acetyl-L-Carnitine)

| Field | Value |
|-------|-------|
| Dose per unit | 500mg |
| Evidence tier | T3 |
| Rationale | Mitochondrial membrane transport; cognitive fatigue; neuroprotective in peripheral neuropathy |
| Contraindications | Thyroid hormone potency — may increase T3/T4 sensitivity; monitor in thyroid conditions |

### Lion's Mane (standardised extract)

| Field | Value |
|-------|-------|
| Dose per unit | 500mg (standardised to ≥30% beta-glucans) |
| Evidence tier | T4 |
| Rationale | NGF synthesis support, traditional use; limited human RCT data |
| Contraindications | None identified; anticoagulant caution (platelet modulation) |

## Packaging specification

- **Format:** Daily sachets (Core 5 combined) + individual unit strips (Longevity/Cognitive as add-ons)
- **Shelf life:** Minimum 12 months at time of receipt; temperature stable (<25°C, RH <60%)
- **Labelling:** Product name, batch number, expiry, "Do not use if seal is broken", Substrate contact (partner hotline), "Not a substitute for medical advice"
- **Language:** English (UK); partner determines additional languages at partner's cost
- **Allergen statement:** Per batch CoA; major allergens declared on packaging

This document is maintained under version control. Proposed changes require:

1. Issue opened with evidence citation
2. Review by at least one director + one external reviewer (clinical or pharmacological)
3. Version bump + changelog entry on merge

Distribution of updated formulations to partners must not exceed 60 days after version bump to allow existing stock draw-down.
